# Frame

A simple screen border overlay for Android.

## Why?

Most border apps on the Play Store use animation engines even for static borders, which wastes battery. Frame just draws a border with no animations running in the background.

## Features

- Customizable color, thickness, opacity, and corner radius
- Optional glow effect
- Pause/resume from notification

## Requirements

- Android 12 or higher
- Overlay permission
